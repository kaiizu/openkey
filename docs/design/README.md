# Prototipos visuales

`conceptos/` conserva el laboratorio visual que se usó para explorar temas y materiales antes de la interfaz actual. **No forma parte de la app**: el servidor solo publica `web/`, así que esta carpeta es un archivo de diseño.

Se puede abrir `conceptos/index.html` directamente en el navegador; usa rutas relativas al repositorio y no hace peticiones de red.
